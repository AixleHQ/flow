## Architecture

### Principle: Web = Inertia, API = JSON

Web controllers (`scope module: :web`) serve **only** Inertia pages and HTML redirects. All JSON endpoints live in `Api::V1` namespace (`namespace :api, defaults: { format: :json }`).

Frontend code uses **typed route helpers** from `shared/api/routes.ts` (generated by `ts_routes` gem) for all API calls — no hardcoded URL strings.

## Changes Made

### Phase 1 (2026-04-09)
- Dual-format cleanup: removed `respond_to` JSON branches from `ConfigItemsController`, `SessionsController`, `ArtifactsController`, `Projects::WorkflowsController#index`
- Serializer → Alba Resource migration: `WorkflowsController`, `StepsController`, `WorkflowRunAssetsController`, `AnalyticsController`
- Added missing attributes to `WorkflowResource`, `SubStepResource`, `WorkflowRunAssetResource`
- Deleted 28 AMS serializer files + 1 concern + 1 dead controller concern

### Phase 2 (2026-04-09)
- **Eliminated `AgentModelsController`**: `RunWorkflowModal` and `AixleBuilder/LandingPage` now receive `agentModels` as deferred Inertia props from their parent controllers. Deleted `web/agent_models_controller.rb` and its route.
- **Eliminated `RepositoriesController#branches`**: `EditRepositoryModal` now receives branches as an Inertia prop (`editBranches`) loaded via `router.reload` when the edit modal opens. Deleted the `branches` action and route.
- **Removed AMS gem**: Converted `ToolResultSerializer` to `ToolResultResource`. Deleted `ApplicationSerializer`, AMS initializer, and removed `active_model_serializers` from Gemfile.

### Phase 3 (2026-04-09)
- **Replaced `ToolResultSerializer` with `ToolResultResource`**: Created `app/resources/tool_result_resource.rb` (Alba, `transform_keys :none`). Deleted `app/serializers/` directory.

### Phase 4 (2026-04-09) — JSON API extraction
- **Moved ALL JSON-serving actions from `web/` to `Api::V1`**:
  - `terminal_sessions_controller` → `api/v1/terminal_sessions_controller`
  - `company/assets_controller` (create/destroy/versions) → `api/v1/company_assets_controller`
  - `company/projects/assets_controller` (create/destroy/versions) → `api/v1/projects/assets_controller`
  - `company/workflows_controller` (show/update/destroy) → `api/v1/workflows_controller`
  - `company/workflows/steps_controller` → `api/v1/workflows/steps_controller`
  - `company/projects/workflows_controller` (show/update/destroy) → `api/v1/projects/workflows_controller`
  - `company/projects/workflows/steps_controller` → `api/v1/projects/workflows/steps_controller`
  - `company/projects/workflow_run_assets_controller` → `api/v1/projects/workflow_run_assets_controller`
  - `company/projects/boards_controller` (create/update/destroy) → `api/v1/projects/boards_controller`
  - `company/projects/board/*` (all sub-controllers: tasks, columns, activities, view_presets, task/*) → `api/v1/projects/board/*`
- **Updated routes**: All JSON routes moved from `scope module: :web` to `namespace :api` / `namespace :v1`. Web routes now serve only Inertia pages and HTML redirects.
- **Created Api::V1 base controllers**: `Projects::ApplicationController`, `Projects::Board::ApplicationController`, `Projects::Board::Task::ApplicationController`, `Projects::Workflows::ApplicationController`, `Workflows::ApplicationController`
- **Updated ALL frontend `fetch`/`apiFetch` calls** to use typed route helpers from `shared/api/routes.ts`:
  - `BoardPage.tsx` — 19+ call sites using `apiV1ProjectTasksPath`, `apiV1ProjectColumnsPath`, etc.
  - `BuilderPage.tsx` — 11 call sites using `apiV1ProjectWorkflowStepPath`, `apiV1WorkflowStepPath`, etc.
  - `Profile/Show.tsx` — 4 calls using `apiV1TerminalSessionPath`, `finishApiV1TerminalSessionPath`
  - `OnboardingPage.tsx` — 2 calls using `apiV1TerminalSessionsPath`, `finishApiV1TerminalSessionPath`
  - `SessionNewForm.tsx` — 1 call using `apiV1TerminalSessionsPath`
  - `AssetsContent.tsx` — `apiBasePath` prop updated to API v1 paths; versions use `versionsApiV1CompanyAssetPath`
  - `Assets/Index.tsx` + `AssetsPage.tsx` — pass `apiV1CompanyAssetsPath()` and `apiV1ProjectAssetsPath(project.id)` to `AssetsContent`
- **Deleted old web controllers**: All JSON-only controllers and their base controllers (`board/`, `workflows/`, `task/`) removed from `web/` scope.
- **Regenerated ts_routes** — all new API paths available as typed helpers.
