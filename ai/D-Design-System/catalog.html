Aixle Design System

Living design system extracted from the Inertia + Mantine frontend

38 Components Mantine v9 Dark Theme 68 Icons

This design system documents the visual language and component patterns used in the Aixle application. All tokens are extracted from the live codebase (mantineTheme.ts) and reflect the current implementation.

Font stack: Poppins (headings/UI) + Inter (body) + JetBrains Mono (code)

Color scheme: Dark mode default with custom semantic variables

Form Patterns

Pattern A: Inertia useForm + Zod

Used in server-rendered forms (Login, Profile, Settings). Validation runs client-side via Zod, submission via Inertia post()/patch().

const { data, setData, post, processing, errors } = useForm({ name: '', email: '' }); const schema = z.object({ name: z.string().min(1), email: z.string().email() }); // On submit const result = schema.safeParse(data); if (!result.success) { /* setError(...) */ return; } post('/profile', { onSuccess: () => notifications.show({ ... }) });

Pattern B: @mantine/form + zodResolver

Used in client-side modals and complex forms (Workflows, Board, Resource modals). Full Mantine form integration with Zod schemas.

const form = useForm({ initialValues: { name: '', type: 'default' }, validate: zodResolver(z.object({ name: z.string().min(1), type: z.string() })), }); // In JSX <form onSubmit={form.onSubmit(handleSubmit)}> <TextInput label="Name" {...form.getInputProps('name')} /> <Select label="Type" data={types} {...form.getInputProps('type')} /> </form>
