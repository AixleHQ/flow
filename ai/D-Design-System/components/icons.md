## ThemeIcon [ico-001]

**Type:** Decoration
**Category:** Icon Container
**Library:** Mantine `ThemeIcon`
**Purpose:** Decorative icon wrapper with background/gradient

### Variants

| Variant | Use Case |
|---------|----------|
| `light` | Feature cards, onboarding steps |
| `gradient` | Highlighted features, landing page |

### Common Props

```yaml
size:     'lg', 'xl'
radius:   'xl' (circular)
color:    dynamic
gradient: { from: '...', to: '...', deg: 45 }
```

### Used In

OnboardingPage (step icons), LandingPage (feature icons).
